## 文档与元数据处理

根 README 改为项目介绍。历史客户复盘、清理证据和内部变更叙事由简短公开说明替代；操作合同中的本机工作区前缀改成通用占位。上游锁保留来源、版本、许可说明和调用合同，移除本机获取回执，并将活跃来源标记为未随仓库安装。旧适配器验收回执不公开或移植为新环境的验收。

代码中的合成测试路径和明确的 `example` 样例保留，以继续验证路径隔离、来源约束和失败处理。技能与操作文档可能提及可选的本地库；相应私有数据目录不属于仓库内容，使用者需要自行准备可用且有权使用的资源。

源码文件、文件检查、静态预览、原生 PowerPoint 显示、动画播放、用户接受是不同证据。案例说明只报告找到的状态，不把文件名、测试或构建成功扩写为用户验收。

本次软件验证覆盖和实际结果记录在 [VALIDATION.md](VALIDATION.md)。案例图片的来源指纹在 [showcase-manifest.json](showcase-manifest.json)。完整客户 PPTX 和第三方模板不提供公开下载。
