# 31类排版使用规则

按当前页的实际功能选择分类，读取对应的详细分析。不同目录中的同功能页可以比较，但仍查看来源页。

- 封面模板（本地资源，未随公开仓库提供）：确立主题、场合和主视觉；把主视觉与主题建立关系；检查主副标题的面积和对齐。
- 目录模板（本地资源，未随公开仓库提供）：展示章节结构与阅读路径；比较列表、分栏、路径和节点式导航；保持章节名称层级。
- 章节模板（本地资源，未随公开仓库提供）：切换到下一叙事阶段；保留整稿主视觉语言，并通过尺度或留白形成停顿。
- 标题模板（本地资源，未随公开仓库提供）：突出本页或本段的核心主张；判断标题本身还是正文是主角；避免将装饰字替代信息层级。
- 结尾模板（本地资源，未随公开仓库提供）：收束结论或明确下一步；比较总结型、行动型与感谢型结尾，按场合选择。
- 一段内容（本地资源，未随公开仓库提供）：说明一个中心观点；区分纯文、文图和主张加证据；保持唯一视觉重心。
- 二段内容（本地资源，未随公开仓库提供）：表达两个信息单元的关系；先确定并列、对照或因果，再选分栏或相连结构。
- 三段内容（本地资源，未随公开仓库提供）：组织三个相关信息单元；比较横向并列、中心辐射、步骤与三角关系；不默认三等分。
- 四段内容（本地资源，未随公开仓库提供）：组织四个信息单元；四象限只用于真实两维关系；区分矩阵、并列和顺序。
- 五段内容（本地资源，未随公开仓库提供）：组织五个信息单元；检查横排、折行和路径布局的阅读顺序与标题长度。
- 六段内容（本地资源，未随公开仓库提供）：组织六个信息单元；比较两行、三列、环形与路径结构；密度过高时分配到相邻页。
- 多段内容（本地资源，未随公开仓库提供）：组织较密的信息并保持主次；按真实层级分组，用主次和顺序组织，不用缩字挤满。
- 人物介绍（本地资源，未随公开仓库提供）：建立人物身份与可信经历；判断个人特写与多人组织图；肖像、身份和证明必须对应。
- 荣誉奖项（本地资源，未随公开仓库提供）：呈现荣誉及其证明；区分突出单项与多项陈列；事实、证书图和机构名称逐一对应。
- 地图排版（本地资源，未随公开仓库提供）：说明地理范围或区域差异；地图用于空间关系；核对区域、标记、统计口径与图例。
- 时间轴图（本地资源，未随公开仓库提供）：说明时间顺序与阶段变化；区分顺序与时长；不等间隔的时间不要伪装成比例轴。
- 架构流程（本地资源，未随公开仓库提供）：说明层级、步骤或流向；先确定层级还是流程；保留箭头端点、分组和连接含义。
- 商业模型（本地资源，未随公开仓库提供）：说明价值、交易或运营机制；模型应表达机制，先写清关系再映射到画布。
- 样机展示（本地资源，未随公开仓库提供）：在载体中展示产品或界面；替换真实界面；检查裁切、透视、比例与设备边缘。
- 金句模板（本地资源，未随公开仓库提供）：强化一句关键表达；看断行、留白和背景关系；引用归属须与当前内容一致。
- 合作伙伴（本地资源，未随公开仓库提供）：说明协作关系或机构覆盖；区分标识陈列与协作网络；关系不能只靠摆放暗示。
- 图文排版（本地资源，未随公开仓库提供）：用文字和图像共同支持主张；判断图片是证据、解释还是气氛；比较左右、上下与穿插关系。
- 表格图表（本地资源，未随公开仓库提供）：表达数量、比例、变化或比较；区分原生图表、原生表格与形状模拟；选择与数据关系匹配的图式。
- 素材图片（本地资源，未随公开仓库提供）：为页面选择有意义的图片；本次没有PPTX来源，不能从空目录推导实页版式。
- 实用素材（本地资源，未随公开仓库提供）：复用实用图形和页面组件；按具体对象检索；损坏原件排除，确认组内对象与媒体关系。
- 风格配色（本地资源，未随公开仓库提供）：建立或协调视觉系统；统计实际使用色与主题槽位，避免把未使用主题颜色当主色。
- 专题模板（本地资源，未随公开仓库提供）：参考同一专题的整套视觉与页序；观察封面与内容页的一致性；专题事实必须替换。
- 数据基座（本地资源，未随公开仓库提供）：突出关键数字及其口径；数字组件仍须完整单位和比较基准，装饰不应压过指标含义。
- 文本组件（本地资源，未随公开仓库提供）：复用局部文字组织与强调方式；先判断文字功能，再复用强调与对齐；不带入原样例文案。
- 装饰形状（本地资源，未随公开仓库提供）：以图形帮助分组或强调；检查形状的作用和组关系；不额外加入无意义编号或线条。
- 发布会（本地资源，未随公开仓库提供）：参考发布场合的叙事与视觉；本次来源均为PDF，没有PPTX可分析；保留资料缺口。
